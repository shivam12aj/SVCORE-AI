## ✨ What is SVCORE AI?

SVCORE AI is a voice-first conversational assistant designed specifically for Indian users. Unlike generic AI assistants, it:

- 🗣️ **Speaks 9 Indian languages** — Hindi, Tamil, Telugu, Bengali, Gujarati, Marathi, Kannada, Malayalam, and English
- 💙 **Detects emotion** — recognizes sadness, anger, or happiness in what the user says and responds accordingly
- 🎙️ **Natural voice interaction** — talk to it like you'd talk to a friend, no typing needed
- 👤 **Gender-selectable voice** — choose a male or female voice persona

## 🚀 Features

- Real-time voice input using the Web Speech API
- Emotion-aware response generation
- Multilingual support across 9 Indian languages
- Natural-sounding text-to-speech output
- Quick-action prompts (career advice, motivation, money tips, business ideas)
- Clean, mobile-first dark UI

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript (vanilla)
- **Speech Recognition:** Web Speech API
- **Text-to-Speech:** ElevenLabs API (with browser TTS fallback)
- **AI / Language Model:** Groq (Llama 3.3 70B)
- **Hosting:** Netlify
